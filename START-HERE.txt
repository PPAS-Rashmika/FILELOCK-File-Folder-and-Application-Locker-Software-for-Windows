FileLock 0.4.1

Delete කළ folder එක නිසා එන "Could not find file" error එකේ fix එක මෙම version එකේ ඇත.

1. FileLock-0.4.1-Setup.exe run කර Install කරන්න.
2. FileLock open කර ඔබගේ දැන් තිබෙන master PIN එක ඇතුළත් කරන්න.
3. Delete කළ item එක select කරන්න.
4. Manage > Remove protection තෝරා confirm කරන්න.

FileLock මුල් NTFS drive එක සහ saved file identities පරීක්ෂා කරයි.
වෙනත් තැනකට ගෙනගිය original file එකක් ඉතිරිව තිබේ නම් එහි මුල් permissions ආපසු ලබාදෙයි.
ඉන්පසු පරණ protection record එක ඉවත් වේ. වෙනත් folder/file වලට permissions ලබා නොදෙයි.
Drive එක නැති නම් හෝ පරීක්ෂාව සම්පූර්ණ කළ නොහැකි නම් recovery record එක ඉවත් නොකරයි.
Deleted folder එක නැවත create කරන්නේ නැත.

Rename/move කළ item සඳහා Manage > Repair moved location භාවිත කරන්න.
අලුත් version එකේ app සහ service දෙකම install කළ යුතුය.
Existing PIN සහ recovery data reset කරන්නේ නැත.
